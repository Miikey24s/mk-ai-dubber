## Terminology / code-switch policy

Added a backward-compatible terminology layer on top of the existing glossary. The core understands `KEEP_EN`, `PREFER_EN`, `VI`, and `CONTEXTUAL`, while legacy `source -> target` glossary files still load as before.

The translation prompt now receives the audience profile plus structured terminology metadata. Deterministic validation runs after translation, after manual review overrides, and before accepting duration rewrites. Strict terms fail closed when the approved display form disappears or a rejected form is introduced.

Display and spoken forms are separate. For example `FVG` remains `FVG` in subtitles while its approved TTS form can be `ép vi gi`; explicit `tts.pronunciation_map` values still override glossary spoken forms.

The golden set covers 16 trading/AI cases including Engulfing, FVG, order block, liquidity sweep, market structure, stop loss, take profit, breakeven, breakout, pullback, BOS, CHoCH, prompt, token, API, and GPU. It caught one real gap (`token` versus plural `tokens`), which is now handled by an explicit alias rather than fuzzy matching.

Translation policy was bumped from v3 to v4 so resume/cache cannot silently reuse prompts from before the terminology contract.

## Reference + spoken phrasing

Reference scoring now retains acoustic quality as the majority of the score and adds a 15% delivery component derived from already-preserved word timing: moderate speech rate, pause density, and complete-phrase evidence. Missing word timing gets a neutral fallback instead of being disqualified. Reference selection policy was bumped from v2 to v3.

On the production reference input for `job-4c8236a32c685a11` (`segments_turns.json`), the selected canonical speaker reference remains segment `6`; the new score therefore does not change the selected voice on this fixture. An earlier exploratory check against `segments_source.json` produced a different top candidate, but that artifact is not the production reference-selection input and was not used as acceptance evidence.

TTS-only phrasing now cleans whitespace around existing punctuation while preserving display subtitles, URLs, numeric normalization, and semantics. It does not invent pauses, SSML, emotion tags, punctuation, or new text. Pronunciation policy was bumped from v1 to v2.
